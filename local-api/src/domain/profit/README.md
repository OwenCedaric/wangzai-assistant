# Profit domain

`profit` 已接入读同步和 SQLite 缓存聚合，不提供写入。

## 接口

```text
GET  /api/cache/profit
POST /api/sync/profit
```

## 当前能力

- 为利润核算读取和聚合订单、商品、财务、罚款等本地缓存证据。
- 支持通过 scheduler 同步利润相关只读数据，例如评价罚款等。
- 前端利润页应 local-first 读取本地缓存，再按需刷新相关域数据。

## 约束

- 不提供 Ozon 写入能力。
- 利润结果必须标明数据来源和缺失项，不能把未回传或未匹配字段当真实值。
- 财务真实流水优先于预估；预估只能作为未回传前的临时展示口径。
