## 运行限制

- 自部署目前以 Windows 源码启动为入口，需按文档安装 Node、Python 及 .NET SDK。
- 官方发行服务、收费模型/OSS、微信及跨境企业接口不随源码附赠；需配置自己的访问权限。
- 本地 CA 和配置有有效期；自动续期、跨机器恢复及生产多实例部署尚未完成验收。
- 全局结构门禁、长时间运行与真实平台变体不能由本次源码和授权链路检查代替。
- npm 锁文件清单不等于全部二进制依赖 SBOM；自行分发安装包时仍需补齐对应许可义务。

欢迎优先贡献可复现的隔离测试、这些失败的修复以及部署文档改进。涉及利润、费用、汇率和账号归属时，必须保留原口径并说明证据。
