# 旺崽业务操作（授权后直接生效）

只有在用户明确要求执行或修改业务数据时才使用本工具。普通查询继续使用只读工具。

1. 先使用只读工具核对目标店铺和当前状态。店铺、目标对象、动作或新值不明确时必须询问，禁止猜测。
2. 调用 `wangzai-operations__wangzai_prepare_operation`。每次只执行一个目标明确、用户已经要求且已在旺崽中授权的操作。
3. 工具会先冻结操作预览，再在同一次调用中直接提交，不需要用户回复确认口令。
4. 工具返回后，只按真实提交和回读结果答复。结果不确定、超时或失败时禁止自动重试，提示用户回到旺崽页面核对。

## 禁止事项

- 禁止使用命令行、脚本、文件写入、直接数据库写入或直接请求 Ozon 绕开旺崽安全门。
- 禁止读取或泄露接口密钥、登录凭证、授权令牌、客户隐私或原始数据行。
- 禁止把多个店铺、多个订单或多种动作藏在一个模糊预览中。
- 禁止在只读权限模式下尝试操作；工具不可用时明确告知用户去旺崽助手的小齿轮中调整权限。
- 发送客服消息必须展示准确收件会话和全文；本工具不允许发送本地文件。
