# 旺崽 Ozon 数据观察器

该扩展由桌面端在 CEF 初始化前自动安装并启用，仅在 `seller.ozon.ru` 中运行。

v2.4 会旁路发现网页已经收到的 Ozon 分析 JSON 响应，并提供接口目录、数据质量、统一记录、完整原始载荷分块回读、关键词精确查询、已验证端点直读和有界只读分页：

- 不修改会员、订阅或权限字段；
- 不伪造接口成功状态；
- 不生成随机指标；
- 不显示页面浮窗；
- 不读取 Cookie、Authorization 或请求头；
- 不把数据发送到外部服务；
- 捕获结果只保存在当前页面内存环形队列中，由桌面端显式回读。
- 同时识别 `seller.ozon.ru` 与 `api.seller.ozon.ru` 的分析响应，兼容旧插件曾涉及的 Premium 状态、销售图表和统计响应路径。
- 大响应不再只剩 25 条预览；完整 JSON 会保留在页面内存中，可按序号分块回读。标准化记录同时保留 `raw` 原字段。
- 已观察到的关键词查询可以只替换搜索词后安全回放；请求方法、接口、登录会话和其余筛选字段保持原样。
- 旧版验证过的畅销榜、类目/品牌、缺货等精确只读端点允许使用当前登录会话直读；路径必须命中固定白名单。
- 只允许对分析、搜索、报表等 GET/POST 查询进行最多 250 页的有界回放；写入语义接口禁止回放。
- 分页逐页保留成功响应；单页网络、HTTP 或非 JSON 异常会返回失败页、状态码与停止原因，不再把已成功页一起抹掉。
- 固定白名单端点的后续页复用已验证的单页读取通道，避免跨域 replay 在同一请求体下偶发 `Failed to fetch`。
- 当前类目/品牌页新增使用的 `get_seller_tree`、`gb/price_segmentation`、`gb/seller/metrics` 已纳入固定只读端点，不再只作为未知响应旁路记录。
- 分页页请求遇到网络错误、非 JSON 网关响应、429 或 5xx 时自动退避重试，结果附带每页尝试次数、总重试次数、续抓序号和完整性校验。

安装来源审计和改造说明见 `NOTICE.md`。
