# 来源与改造说明

- 用户提供样本：`数据分析.zip`
- 原始 SHA-256：`1E6FC7F05F8637349FCE3C860BD972510988D7168CBF33320E353218D5379C97`
- 原项目目录名：`pivot-table-master`
- 原许可证：木兰宽松许可证，第 2 版（随包保留为 `LICENSE`）

原始样本仅包含页面权限与响应改写逻辑，没有可供项目调用的数据采集接口。本项目没有复制其中的权限伪造、随机数据、全局 `JSON.parse` 改写或页面浮窗实现，而是重新实现了只读响应观察器。

v2.4 将旧插件曾涉及的响应路径作为兼容基线保留：Premium 状态、销售图表、统计数据，以及后续实测确认的畅销榜、搜索词、类目、品牌、对比和缺货机会接口都会记录真实服务器原始响应。超过内联阈值的响应保存完整 JSON，并通过分块接口回读；预览截断不再等于原始数据丢失。关键词回放只允许修改已观察请求中的搜索词字段；端点直读必须命中固定只读白名单，并继续使用当前账号的真实登录权限。分页逐页容错并对网络错误、非 JSON 网关响应、429 和 5xx 自动退避重试；结果回传失败页、HTTP 状态、停止原因、每页尝试次数、续抓序号和完整性校验。固定白名单端点的分页统一复用已验证的单页读取通道，避免通用 replay 偶发跨域失败。当前类目/品牌页使用的 `get_seller_tree`、`gb/price_segmentation`、`gb/seller/metrics` 也已纳入只读白名单。
